## Project Overview
- **License:** MIT License (100% Permissive Open Source)
- **Author:** Jonas Hoekman
- **Primary Target:** macOS (Apple Silicon M3) in Clamshell Mode + HDMI 5.1.2 Dolby Atmos Soundbar
- **Backup / Portable Target:** Raspberry Pi 4/5 with official 7" DSI Touchscreen (800x480 Kiosk Mode)
- **Core Engine:** Dual-Deck Web Audio API with real-time Mid/Side Vocal Reducer Worklet, 3-Band EQ, Bipolar Filter, and Split-Hand External USB Keyboard Matrix.
